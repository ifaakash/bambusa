# Bambusa

High-performance e-commerce landing page for Bambusa, a premium bamboo socks brand.

## Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Database**: PostgreSQL
- **Analytics**: Umami

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Set up Environment Variables**:
    Copy `.env.example` to `.env` and fill in your database and analytics details.
    ```bash
    cp .env.example .env
    ```

3.  **Run Development Server**:
    ```bash
    npm run dev
    ```

4.  **Build for Production**:
    ```bash
    npm run build
    ```

## Features
- **Mobile First**: Optimized for thumb-friendly navigation.
- **Performance**: High Lighthouse scores.
- **Waitlist**: Email capture with PostgreSQL storage.
- **Analytics**: Privacy-friendly analytics with Umami.
